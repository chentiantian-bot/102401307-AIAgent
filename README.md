# 校园失物招领 Web 平台
结对编程作业，前端单页面应用，使用 localStorage 在浏览器本地存储数据。

## 功能介绍
1. 发布寻物/招领信息，填写物品名称、分类、描述、地点、联系方式
2. 首页卡片展示全部物品信息，支持关键词搜索、物品分类筛选
3. 点击卡片查看详情，一键复制联系方式
4. 修改物品状态：待认领 / 已找到 / 已归还
5. 内置单元测试脚本，浏览器控制台执行测试

## 技术栈
HTML + CSS + JavaScript，本地 localStorage 存储，无需后端服务器。

## 使用方法
1. 下载仓库代码，在本地用浏览器打开 index.html
2. 点击【发布招领】按钮填写表单提交信息
3. 顶部搜索框和下拉分类筛选物品卡片
4. 点击卡片打开详情弹窗，复制联系方式，修改物品状态
5. 打开浏览器控制台，输入 `runTest()` 执行单元测试
